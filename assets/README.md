# Origin Recode: Second World — Official Website

A responsive, dark premium-style starter website using black, blue, and gold.

## Files
- `index.html` — page content
- `style.css` — layout, colors, animations, responsive styles
- `script.js` — mobile navigation, particles, scroll reveals
- `assets/orsw-logo.png` — provided ORSW logo

## Before publishing
1. Open `script.js`.
2. Find `const robloxGameUrl = "";`
3. Paste your Roblox experience URL between the quotes.
4. Edit the temporary copy in `index.html` so every description accurately matches the game.
5. Replace the placeholder update card with a real announcement when ready.

## Preview locally
Open `index.html` in a modern browser. For a local development server, you can open the folder in Visual Studio Code and use a local server extension, but it is not required for a basic preview.

## Publish with GitHub Pages
1. Create a public repository, for example `Origin-Recode-Second-World`.
2. Upload all files and folders in this project (not just the ZIP file).
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to deploy and use the URL shown in Settings → Pages.

Do not put passwords, private keys, or private player information in this public repository.
